# Vehicle Sales Visualization Platform

车辆数据采集与可视化平台，源于课程实践，旨在为学习网页数据采集、数据处理和可视化展示的开发者提供项目参考。

我希望通过持续整理和完善，将这个项目逐步建设为一个容易运行、理解和扩展的车辆数据分析示例。

> **项目状态：早期整理与完善阶段。** 当前仓库尚未上传完整文件，运行文档和依赖说明也在补充中，暂不保证直接克隆即可运行。下文中的路线图属于后续开发计划，不代表已经实现的功能。

## 项目背景

本项目最初是学习期间完成的课程作业，参考了 B 站相关教学内容，实践了从网页数据采集到可视化展示的基本流程。原始实践的数据来源为 [懂车帝](https://www.dongchedi.com/)。

公开仓库的目的是分享学习成果，为有类似需求的学习者提供参考，并逐步完善项目的可复现性和维护方式。相关教程链接和参考资料将在整理后补充。

目前仓库已包含车辆数据采集与可视化相关代码，以及应用、数据库和词云脚本等文件。由于文件尚未整理完整，具体可运行功能及其操作步骤将在验证后逐项补充。

## 数据说明

项目早期实践使用的数据来自懂车帝。数据的采集时间、字段含义、处理方式和可再分发范围仍需进一步整理；使用前请自行核对来源、适用条件和时效性。

后续计划提供来源明确的演示数据，并支持用户导入自己有权使用的数据。使用数据采集代码时，请遵守数据来源网站的适用规则，合理控制请求频率。

本项目中的图表和统计结果主要用于学习与技术演示，其准确性取决于输入数据的完整性和质量。
